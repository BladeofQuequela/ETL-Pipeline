# ETL Pipeline (Docker + Python + PostgreSQL)

## Что делает? Автоматически извлекает данные из Excel, чистит их и загружает в базу данных PostgreSQL, развернутую в Docker.

## Как запустить?
### – скачать датасет UCI Retail и закинуть его в папку data/
### – выполнить docker compose up --build -d

# Стек: Python, Pandas, SQLAlchemy, Docker, PostgreSQL
